Загрузка данных

Два независимых режима: исходные ВНД для полного анализа и ранее сохранённые машинные отчёты NORMATRIX для быстрого суммарного анализа без повторного OCR и чтения документов.

1. ВНД для анализа

полный цикл обработки
Перетащите 1–300 ВНД или выберите файлы

PDF, DOCX, DOC, XLSX, XLS, TXT, JPG/JPEG, PNG, TIFF, WEBP, ZIP. В одном ZIP могут находиться основной текст, приказ, приложения, изменения и изображения страниц.

2. Отчёты ВНД для портала

без повторного OCR
Перетащите до 300 файлов .normatrix

Это машинные отчёты, созданные самим NORMATRIX. Можно также загрузить ZIP‑пакет, содержащий несколько файлов .normatrix. Они предназначены только для повторной загрузки в портал, а не для чтения человеком.

🔒
ZERO PERSISTENCE. Исходные документы и машинные отчёты существуют только в памяти текущей вкладки. После очистки/обновления страницы данные сессии не восстанавливаются.

Структурные подразделения

Рекомендации формируются по связанным замечаниям и объединяются по первопричине. Клик ведёт от рекомендации к ВНД → пункту → исходному тексту.

Правовой мониторинг

Результаты формируются по каждому ВНД в понятной форме: документ → реквизиты → структурный элемент → сопоставляемый акт → меры → актуализация. Технические ID не используются как основной способ представления.

Сначала ссылки извлекаются локально. Интернет‑верификация должна использовать только официальные источники и не передавать полный текст ВНД.

Внешний endpoint не настроен: портал покажет найденные ссылки и официальные источники для проверки, но не будет выдавать ложный статус «актуально».

Качество данных

Контроль отсутствующих ID, нераспознанных пакетов, дублей файлов, неподдерживаемых форматов и неполного охвата реестра.
