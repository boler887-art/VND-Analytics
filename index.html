Загрузка ВНД

Поддерживаются одиночные документы и ZIP‑пакеты одного ВНД. Рекомендуемый формат архива: VND-000001.zip.

Перетащите 1–300 ВНД или выберите файлы

PDF, DOC/DOCX, XLS/XLSX, TXT, JPG/JPEG, PNG, TIFF, WEBP, ZIP. Старый бинарный DOC портал пытается извлечь локально без отправки файла наружу. Для сканов действует безопасный автоматический OCR, а оставшиеся страницы можно дораспознать вручную очередью. В одном ZIP могут находиться основной текст, приказ, приложения, изменения и изображения страниц.

🔒
Файлы остаются в памяти текущей вкладки. Код не использует localStorage, sessionStorage, IndexedDB или cookies для пользовательских документов. Внешняя правовая проверка отключена для текста ВНД и может передавать только реквизиты НПА после настройки защищённого backend.

Выявленные замечания

Дубли и смысловые пересечения

Точные и близкие нормы группируются с объяснением сходства. Процент используется только как аналитический ориентир.

Противоречия

Потенциальные конфликты сроков, модальности, полномочий, терминов и субъектов ответственности.

НПА и нормативные ссылки

Сначала ссылки извлекаются локально. Интернет‑верификация должна использовать только официальные источники и не передавать полный текст ВНД.

Внешний endpoint не настроен: портал покажет найденные ссылки и официальные источники для проверки, но не будет выдавать ложный статус «актуально».

Качество данных

Контроль отсутствующих ID, нераспознанных пакетов, дублей файлов, неподдерживаемых форматов и неполного охвата реестра.
