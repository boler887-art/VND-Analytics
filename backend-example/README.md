# Backend example

Этот каталог содержит минимальный stateless-пример контракта Legal Verification Module.

Он НЕ является юридической базой и намеренно не делает вид, что проверил норму, если интеграция с официальным источником не реализована.

Запуск:

```bash
node server.mjs
```

Затем в `config.json`:

```json
"endpoint": "http://localhost:8787/verify"
```

Для production разместите backend во внутреннем/защищённом контуре и реализуйте проверку по разрешённым официальным источникам.
