# v1.0.3

- Старый `.DOC` больше не отбрасывается: добавлено локальное best-effort извлечение текста из RTF/DOC и бинарного Word (Windows-1251/Unicode runs).
- Если `.DOC` прочитан частично, портал помечает выводы как требующие сверки с оригиналом; если текст не извлечён надёжно, ошибка относится только к этому файлу.
- Автоматический OCR-лимит увеличен до 40 страниц/изображений для безопасного первичного анализа.
- Добавлена кнопка `OCR: распознать ожидающие (N)` — страницы сверх автоматического лимита обрабатываются локальной последовательной очередью без повторной загрузки.
- После ручного OCR аналитика и замечания автоматически пересчитываются.
- Счётчик качества теперь показывает число ожидающих OCR-страниц, а не только число файлов.

# v1.0.2

- Код `MAIN` больше не обязателен.
- Добавлено автоматическое определение основного источника по имени, типу ВНД, содержимому и совпадению с реестром.
- После извлечения текста роли файлов уточняются по содержимому (приказ/приложение/изменение/проект).
- Для последовательности изображений поддерживается автоматическое определение единого основного скана.
- В карточке пакета добавлен ручной выбор «Сделать основным».
- Предупреждение «MAIN не указан» заменено предупреждением только при реально низкой уверенности определения.

# Changelog

## 1.0.0 — 2026-09-23
- Портал перепрофилирован на аналитику ВНД.
- Автозагрузка корневого реестра и структуры без кэша.
- VND_ID присвоены 314 ВНД текущего реестра.
- Поддержаны ZIP-пакеты ВНД и документы PDF/DOCX/XLSX/TXT/JPG/PNG/TIFF/WEBP.
- Добавлены локальное извлечение текста, OCR, анализ дублей/противоречий/отсылочных норм.
- Добавлены 8 категорий правового мониторинга, карточки ВНД, рекомендации СП и экспорт.
- Реализован zero-persistence режим пользовательских документов.
- Внешняя правовая проверка отделена и отключена до настройки защищённого backend.

## 1.0.1 — 2026-09-23
- Исправлена классификация: при высокой схожести сначала проверяется логическое противоречие, и только затем дубль.
- Исправлено извлечение ссылок вида «статья 64 АППК РК» — номер статьи больше не теряется.
- Исправлен фильтр статуса ВНД.
- Улучшено построчное извлечение текста PDF для распознавания пунктов.
- Добавлен OCR-fallback для сканированных PDF в пределах лимита OCR.
- Добавлен контроль низкой уверенности OCR и отсутствия MAIN в ZIP.
- Ограничено фактическое количество пар междокументного сравнения для устойчивости на больших массивах.
- Автоматический запуск после загрузки отключён: сначала пользователь видит проверку пакетов, затем запускает анализ.
- Добавлена явная диагностика недоступности браузерных библиотек CDN.
