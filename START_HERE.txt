NORMATRIX VND Analytics v1.2.0 — ПОЛНАЯ ЗАМЕНА

1. Загрузите содержимое этой папки в корень репозитория GitHub Pages.
2. Сохраняйте имена `vnd_master.xlsx` и `structure.xlsx` неизменными; меняйте только строки/содержание при сохранении шапок.
3. После обновления сайта выполните Ctrl+F5 один раз.
4. Исходные ВНД загружайте через «ВНД для анализа».
5. Ранее сохранённые `.normatrix` — через отдельную зону «Отчёты ВНД для портала».
6. Официальная отчётность содержит только подтверждённые специалистом замечания.

Новая версия включает Conflict Engine 2.0 и единую карточку ВНД.
