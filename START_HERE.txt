NORMATRIX VND Analytics v1.0

1. Загрузите ВСЕ файлы и папки из этого каталога в корень репозитория GitHub Pages.
2. Не переименовывайте vnd_master.xlsx и structure.xlsx.
3. В vnd_master.xlsx уже присвоены VND_ID VND-000001 ... VND-000314.
4. Один комплект материалов одного ВНД рекомендуется архивировать как VND-XXXXXX.zip.
5. Внутри архива файлы могут называться обычными именами. MAIN необязателен: портал определит основной документ автоматически; ORDER/APP/AMD тоже распознаются по имени и содержимому. При сомнении основной файл можно выбрать вручную.
6. После открытия сайта пользовательские документы отсутствуют. Они появляются только после загрузки в текущую вкладку и не сохраняются порталом.
7. Legal Verification Module по умолчанию НЕ настроен и не отправляет ВНД в Интернет.
8. structure.xlsx в пакете — стартовый справочник. При наличии официальной структуры замените строки, сохранив шапки.

Подробнее: README.md и папка docs/.
