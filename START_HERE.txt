NORMATRIX VND Analytics v1.1.2 — ПОЛНАЯ ЗАМЕНА

1. Загрузите содержимое этой папки в корень репозитория GitHub Pages.
2. vnd_master.xlsx и structure.xlsx должны оставаться в корне.
3. ВНД загружаются через блок «ВНД для анализа».
4. Машинные отчёты .normatrix загружаются отдельно через «Отчёты ВНД для портала».
5. Официальный человекочитаемый отчёт и Приложение 3 включают только замечания, подтверждённые специалистом. Отклонённые и неподтверждённые замечания в официальный результат не попадают.
6. Для корректного распределения по подразделениям замените стартовое содержание structure.xlsx на фактическую действующую структуру, сохранив шапки.
7. RAR текущей браузерной сборкой не поддерживается — используйте ZIP.
8. Онлайн-проверка НПА требует отдельного защищённого Legal Verification endpoint.
