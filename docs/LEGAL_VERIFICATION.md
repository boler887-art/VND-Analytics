# Legal Verification Module

`config.json` → `legalVerification.endpoint`.

До указания endpoint кнопка «Проверить НПА» не отправляет документы в Интернет и не присваивает нормативной ссылке ложный статус «актуально».

## Контракт запроса

```json
{
  "references": [
    {"id":"LR-0001","raw":"АППК РК, статья 64 часть 3"}
  ]
}
```

Полный текст ВНД в запрос не входит.

## Ожидаемый ответ

```json
{
  "results": [
    {
      "id":"LR-0001",
      "status":"подтверждено",
      "act":"АППК РК",
      "article":"64",
      "verifiedAt":"2026-09-23T10:00:00+05:00",
      "source":"https://zan.gov.kz/...",
      "note":"Норма действует"
    }
  ]
}
```

Рекомендуемые официальные источники перечислены в `legal_sources.json`.
