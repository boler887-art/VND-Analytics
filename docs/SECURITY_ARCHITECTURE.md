# Безопасность и ZERO PERSISTENCE

1. Пользовательские ВНД хранятся только в JavaScript-памяти текущей вкладки.
2. Код не использует localStorage, sessionStorage, IndexedDB и cookies для документов/результатов.
3. F5/перезагрузка страницы очищает рабочую сессию.
4. Кнопка «Очистить сессию» отзывает созданные Object URL и очищает массивы документов/результатов.
5. `vnd_master.xlsx` и `structure.xlsx` являются системными файлами сайта и остаются в корне.
6. CDN загружает только программные библиотеки; байты ВНД в CDN не отправляются.
7. Для полностью изолированной корпоративной среды рекомендуется скачать библиотеки в папку `vendor/` и заменить CDN-ссылки локальными.
8. Legal Verification Module по умолчанию не настроен и не получает текст ВНД.
