# Формат машинного отчёта NORMATRIX (.normatrix)

`.normatrix` — переносимый машинный пакет анализа одного ВНД. Он предназначен для повторной загрузки в NORMATRIX VND Analytics и не является человеческим отчётом.

## Что содержит
- VND_ID;
- снимок реквизитов ВНД на момент анализа;
- структурированные нормы (источник, страница, пункт, текст);
- техническое резюме файлов;
- сигнатуру анализа;
- решения специалиста по замечаниям, если они были подтверждены/отклонены.

Исходные PDF/DOC/DOCX/JPG внутри `.normatrix` не сохраняются.

## Повторная загрузка
На странице «Загрузка данных» используется отдельный блок «Отчёты ВНД для портала». Можно загрузить отдельные `.normatrix` либо ZIP, содержащий несколько `.normatrix`.

Портал исключает повторный VND_ID из текущей сессии, привязывает отчёт к актуальному `vnd_master.xlsx`, затем пересчитывает междокументные дубли и противоречия.

Если требуется открыть исходную страницу документа, одновременно должен быть загружен сам исходный ВНД; один `.normatrix` хранит только доказательный текст и координаты, а не оригинал.


## Статусы и официальный отчёт
- `confirmed` — включается в человекочитаемый проверенный отчёт, рекомендации СП и Приложение 3.
- `ai` — кандидат системы; хранится в `.normatrix`, показывается в портале, но не включается в официальный отчёт.
- `legal` — требует юридической проверки; хранится в `.normatrix`, но не включается в официальный отчёт до подтверждения.
- `rejected` — решение специалиста сохраняется в `.normatrix`, чтобы замечание не возникало заново после импорта, но в официальный отчёт, Приложение 3 и рекомендации СП не включается.

`.normatrix` содержит извлечённые фрагменты текста ВНД и должен обращаться как с конфиденциальным рабочим файлом, даже несмотря на отсутствие оригинальных PDF/DOC/DOCX/JPG внутри пакета.
