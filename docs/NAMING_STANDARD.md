# Стандарт именования ВНД-пакетов

Главное правило: один самостоятельный ВНД = один постоянный `VND_ID`.

## Архив
`VND-000001.zip`

## Файлы внутри
- `MAIN__RU__SIGNED.pdf`
- `MAIN__KZ__SIGNED.pdf`
- `ORDER.pdf`
- `APP01.pdf`
- `APP02.xlsx`
- `AMD01.pdf`
- `MAIN__P001.jpg`
- `MAIN__P002.jpg`

ID не меняется при смене руководителя, подразделения, названия или выходе изменений. Новый самостоятельный ВНД получает новый ID.
