# NORMATRIX VND Analytics v1.2.1

Веб-портал временного анализа внутренних нормативных документов без постоянного хранения пользовательских ВНД.

## Два режима загрузки

1. **ВНД для анализа** — PDF, DOCX, DOC, XLSX/XLS, TXT, изображения, ZIP-пакеты одного ВНД.
2. **Отчёты ВНД для портала** — `.normatrix` или ZIP с `.normatrix`; OCR/парсинг исходного документа повторно не выполняется.

## v1.2.1

- Conflict Engine 2.0 с разбором субъекта, функции, объекта, полномочий, обязанностей, ответственности, модальности, сроков, условий, исключений, сферы действия, контроля и основания.
- Единая карточка ВНД во всех разделах.
- Человекочитаемый раздел «Противоречия» с Документом А/Б и сравнительной матрицей.
- Подтверждённое противоречие автоматически относится к PM02 «Противоречащие нормы».
- Технические ID остаются служебными; основное отображение использует наименование ВНД, номер и дату.

Содержание реестра/структуры можно менять без изменения кода, если шапки таблиц остаются неизменными.

## Правило официальной отчётности

В официальный Excel/PDF, рекомендации СП и Приложение 3 включаются только замечания со статусом **«Подтверждено специалистом»**. Отклонённые и неподтверждённые кандидаты туда не попадают.

## Конфиденциальность

Пользовательские ВНД и результаты текущей сессии не сохраняются в localStorage/sessionStorage/IndexedDB/cookies. После очистки/перезагрузки исходные данные текущей сессии исчезают. Для повторного использования анализа скачивайте `.normatrix`.
