# NORMATRIX VND Analytics v1.2.3 — FINAL QA

Полная сборка для замены портала GitHub Pages.

## Критические исправления загрузки
- загрузка исходных файлов больше не зависит от `package_schema.json`;
- JSZip поставляется локально в `vendor/jszip.min.js`;
- ZIP с кириллическими именами CP866/Windows-1251/UTF-8 поддерживаются;
- вложенные папки в `VND-XXXXXX.zip` поддерживаются;
- недоступность PDF/OCR/DOCX/XLSX-библиотеки не делает кнопку загрузки «мёртвой»: файл добавляется в сессию, а недоступная операция показывается отдельно;
- исправлена инициализация кнопки правовой проверки;
- отдельная загрузка `.normatrix` и ZIP с несколькими `.normatrix` сохранена.

## Аналитика
Сохранены единая карточка ВНД, Conflict Engine 2.0, правовой мониторинг, дубли, НПА/ссылки, качество данных, рекомендации и проверенные выгрузки.

## Официальные выгрузки
В Excel/PDF и Приложение 3 попадают только замечания со статусом «Подтверждено специалистом». Отклонённые и неподтверждённые кандидаты не включаются.

## Конфиденциальность
Нет зависимости от ChatGPT/OpenAI и нет передачи ВНД в OpenAI. Пользовательские данные не сохраняются в localStorage/sessionStorage/IndexedDB/cookies.

## Установка
Полностью замените содержимое репозитория файлами этой сборки, дождитесь GitHub Pages и выполните Ctrl+F5 один раз.
