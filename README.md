# NORMATRIX VND Analytics v1.0.1

Статический аналитический портал ВНД, рассчитанный на GitHub Pages и временную (session-only) работу с 1–300 ВНД.

## Что уже работает

- автоматическое чтение `vnd_master.xlsx` и `structure.xlsx` из корня без кэширования;
- 314 присвоенных постоянных `VND_ID` в текущем реестре;
- загрузка одиночных PDF/DOCX/XLSX/TXT/изображений и ZIP-пакетов ВНД;
- связь архива `VND-000001.zip` с соответствующей строкой реестра;
- локальное извлечение текста из PDF, DOCX, XLSX, TXT;
- OCR-fallback для сканированных PDF и OCR отдельных изображений в пределах лимита;
- OCR изображений JPG/PNG/TIFF/WEBP (с лимитом автоматического OCR из `config.json`);
- выделение пунктов/фрагментов и нормативных ссылок;
- локальный предварительный поиск точных и близких дублей;
- локальный предварительный поиск потенциальных противоречий: разные сроки, обязанность/право, отрицание, различающиеся управленческие термины; конфликт проверяется раньше дублирования;
- восемь категорий правового мониторинга;
- карточка каждого ВНД и переход к исходному файлу/странице;
- рекомендации по структурным подразделениям;
- статусы замечания: выявлено → подтверждено / отклонено / юридическая проверка;
- экспорт аналитического Excel, JSON и печатного отчёта;
- ZERO PERSISTENCE: пользовательские документы не записываются в localStorage/sessionStorage/IndexedDB/cookies.

## Важно про «ИИ» и правовую верификацию

В поставляемом статическом GitHub Pages пакете работает локальный аналитический движок правил и смысловой близости. Он не выдаёт свои гипотезы за официальное правовое заключение.

Автоматическая проверка актуальности законодательства через Интернет требует отдельного защищённого backend `Legal Verification Module`. В `config.json` поле `legalVerification.endpoint` оставлено пустым. До настройки backend портал извлекает нормативные ссылки и показывает официальные источники, но честно оставляет статус «не проверено».

Полный текст ВНД не должен передаваться такому модулю. Контракт рассчитан на передачу только реквизитов НПА.

## Запуск

### GitHub Pages
1. Создайте/очистите репозиторий.
2. Загрузите **содержимое этой папки в корень** репозитория.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/(root)`.
4. Откройте опубликованную ссылку.

### Локальная проверка
Открывать `index.html` двойным кликом нельзя: браузер блокирует чтение Excel через `file://`.

В папке проекта выполните:

```bash
python -m http.server 8080
```

и откройте `http://localhost:8080`.

## Корневые данные

- `vnd_master.xlsx` — реестр ВНД; содержание строк можно менять, шапки не менять.
- `structure.xlsx` — справочник структуры; содержание можно менять, шапки листа `STRUCTURE` не менять.
- `config.json` — лимиты и параметры.
- `rules.json` — правила локального мониторинга.
- `aliases.json` — варианты Ф.И.О./названий.
- `glossary.json` — корпоративная терминология.
- `legal_sources.json` — разрешённые официальные источники.

## Стандарт пакета одного ВНД

Рекомендуемое имя архива:

`VND-000123.zip`

Внутри можно использовать:

- `MAIN.pdf` — основной текст;
- `ORDER.pdf` — приказ/акт утверждения;
- `APP01.pdf`, `APP02.xlsx` — приложения;
- `AMD01.pdf` — изменение;
- `MAIN_RU.docx`, `MAIN_KZ.docx` — языковые версии;
- `MAIN_P001.jpg`, `MAIN_P002.jpg` — страницы-изображения.

Архив и файлы анализируются только в памяти текущей вкладки.

## Ограничения браузерной версии

- старый бинарный `.doc` локально не извлекается — лучше конвертировать в DOCX/PDF;
- постраничная нумерация DOCX недоступна без предварительной конвертации в PDF;
- OCR большого количества сканов может быть ресурсоёмким;
- глубокая юридическая интерпретация и актуальность НПА должны подтверждаться специалистом/защищённым Legal Verification backend.

## Что нужно заменить перед рабочим использованием

`structure.xlsx` в этом пакете создан как стартовый справочник на основе ответственных блоков из предоставленного реестра. Если у вас есть утверждённый файл структуры, замените **содержание** листа `STRUCTURE`, сохранив его шапки. Код портала менять не требуется.

## Библиотеки браузера

`index.html` подключает SheetJS, JSZip, Mammoth, PDF.js и Tesseract.js через CDN. Эти библиотеки загружают программный код в браузер, но портал не отправляет им ваши ВНД как файлы. Для полностью закрытого контура положите локальные копии библиотек в `vendor/` и замените CDN-ссылки в `index.html`.

## Глубокий ИИ-анализ

В текущей статической версии включён безопасный локальный аналитический слой. Полноценный LLM-анализ функций, логики и правовых смыслов сотен документов следует подключать только к локальной модели на рабочем компьютере либо к защищённому корпоративному/intranet backend. Внешний облачный ИИ для полного текста ВНД по умолчанию не подключён.
