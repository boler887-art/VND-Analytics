## Намеренно не включено / требует отдельной инфраструктуры

1. **Полноценный LLM/ИИ-агент не встроен в статический GitHub Pages.** Текущая версия использует локальные правила, сравнение текста и эвристики. Для глубокого смыслового/правового анализа полного текста ВНД нужен локальный ИИ на рабочем компьютере либо защищённый intranet backend.
2. **Legal Verification Module не подключён к реальной правовой базе.** `config.json → legalVerification.endpoint` пустой. Портал извлекает реквизиты НПА и не выдаёт ложный статус «актуально».
3. Старый бинарный `.doc` учитывается в пакете, но текст не извлекается; требуется DOCX/PDF.
4. Постраничная привязка DOCX ограничена форматом Word; для точной страницы рекомендуется утверждённый PDF.
5. Автоматический OCR ограничен `maxAutoOcrImages` в `config.json`; оставшиеся изображения помечаются как требующие OCR.
6. `structure.xlsx` в поставке — стартовый справочник на основе ответственных лиц, а не утверждённая оргструктура. Его содержание следует заменить на фактические структурные подразделения при сохранении шапок.

## Ограничение тестовой среды

Полный headless-browser E2E с загрузкой CDN-библиотек не завершён в контейнере проверки, потому что среда не имеет DNS-доступа к `cdn.jsdelivr.net`. Сам портал через локальный HTTP-сервер доступен, а программные и данные проверки выполнены. Для production рекомендуется разместить браузерные библиотеки локально в `vendor/`, чтобы работа не зависела от CDN/корпоративного фильтра.

## v1.0.3 — OCR queue и старый DOC

- Проверен синтаксис JavaScript после добавления очереди OCR и legacy DOC parser.
- OCR сверх автоматического лимита больше не является тупиковым состоянием: ожидание сохраняется на уровне конкретных страниц, доступна ручная последовательная обработка.
- Старый `.doc` обрабатывается локально best-effort: RTF-контейнер очищается от управляющих последовательностей; для бинарного Word извлекаются читаемые Windows-1251 и UTF-16LE последовательности.
- При низкой надёжности legacy DOC система не выдаёт файл за полностью распознанный и требует сверки/ручной проверки.
